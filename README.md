# Australia Travel Handbook 2026

Static travel handbook for Victoria Cheng.

## Files

- `index.html` - page structure
- `styles.css` - visual design and responsive layout
- `script.js` - content data, navigation, language and currency toggles
- `package.json` - local validation scripts
- `tools/build-check.mjs` - zero-dependency build check for the static site

## Commands

- `npm run build` - validate key files, asset paths, page sections, and JavaScript syntax
- `npm run serve` - serve the project locally on `http://127.0.0.1:4173`
